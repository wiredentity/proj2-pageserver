# Proj2-pageserver
A simple webserver used to create an understanding of how to combine Flask with Docker for better and easier hosting.

# How-To
Use Docker and Flask to host webserver. Go to `localhost:openport/request` to request file. Supports html and css files, placed in `./templates`.

- Bad requests will throw 403 Error

- If request not in templates, will throw 404 Error
